# Playtests

Camera feel, readability and difficulty are judged by hand on a real machine, not by a test. One file per session: `YYYY-MM-DD-milestone.md`.

Each note records:

- the milestone and the build or commit played
- what was tried, with exact steps a stranger could repeat
- what felt wrong, in plain words (`zoom out loses the ditch`, `the failure line is unreadable at holding zoom`)
- what was fixed in the same session, and what is now a line in `07-milestones.md`

Screenshots are welcome but never required. A written note is the deliverable.
